# abhijeetbishayee-drb.github.io

Forwarding site. The GitHub account `abhijeetbishayee-drb` was renamed to `sectorchakra` (2026-10).
GitHub Pages does not redirect after a rename, so this organisation keeps the old name and serves a
page at every old address (`index.html` for `/`, `404.html` for every other path) that forwards to
the same path on `https://sectorchakra.github.io`, keeping query string and hash. It also reserves
the old name so nobody else can claim it and break GitHub's repository redirects.

Do not add repositories named like the moved ones (nifty-heatmap-web, nifty-pcr-tracker, ...) to
this organisation: a same-named repo here would take over the old URLs and GitHub's redirects.
